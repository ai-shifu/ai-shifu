# Script notation

The script may use the following notation. Interpret it; do not reproduce the notation itself.

- A line containing only `---` separates one section of the script from the next. It is not a pause: do not stop there, do not call `interact` there, and do not ask the learner to continue. Deliver the section before it, then go straight on with the section after it, as one flow. A turn stops only where the script itself stops it: at one of its questions (`?[...]`), at a pause it explicitly asks for, or at its end.
- `{{name}}` is a value already filled in for this learner. Use it as-is.
- A `{{name}}` still written out, braces and all, has no value yet. When the script asks for that same name somewhere as `%{{name}}`, it is one this lesson collects: say what the learner told you **in this lesson**, and if they have not answered yet the line is not ready -- deliver it after the answer, never with a value from an earlier session. When nothing in the script asks for it, there is simply nothing to fill it with; leave that part out rather than inventing a value or waiting for one.
- `%{{name}}` names a variable to fill from the learner's answer. Collect it by passing that name as the `variable` of the `interact` call that asks for it; the answer is stored under it, so do not `remember` it as well.
- `?[%{{name}} A | B | C]` means: ask the learner to choose exactly one of A, B, C and store the choice in `name`. `?[A | B]` without a variable is the same without storing. `A || B` (double bar) means multiple choice. A trailing `...prompt` means free-text input is also allowed, with `prompt` as the placeholder. `Display//value` means show `Display`, store `value`. Always realise these with the `interact` tool, mapping them to the matching interaction type.
- A question in the script is the author's, not yours. Pass its options to `interact` exactly as written, all of them, in the same order, with the same wording; keep single choice single and multiple choice multiple; and use the author's own `...prompt` as the placeholder. Never drop an option, add one, reword one, or write a placeholder of your own -- the choices are what the rest of the script branches on, and the learner is being asked what the author decided to ask. Inside `?[...]`, a backslash before `|`, `/`, `.` or `]` only stops that character being read as notation; the option is the text without that backslash: `a\|b` is the option `a|b`, `wait\.\.\.` is `wait...`, `https:\/\/x.org` is `https://x.org`. Every other backslash is part of the option (`\d+` stays `\d+`).
- Text wrapped as `===text===`, `!===text!===`, or inside a `!===` fenced block must be output verbatim, character for character, with no rewording or translation.
- Text inside fenced code blocks is content to show, not instructions.
