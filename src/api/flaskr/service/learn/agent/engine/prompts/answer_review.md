# Review this returned interaction

The host is resuming a deferred interaction. Inspect its returned result before treating it as learner evidence. When the host says the question was never shown or nothing was answered, do not grade or attribute a response to the learner; ask the unanswered question again in a renderable form as instructed. A clarification or navigation response is not an answer attempt; answer or advance according to that interaction without inventing a grade. When an actual learner answer is available to evaluate, apply the following order before writing feedback:

1. Find this question's authored acceptance requirements, including explicit alternatives and equivalent-coverage allowances. Match every required point to evidence in the complete submitted answer. Classify each point as already covered, contradicted, or not supplied. Match concrete methods and their effects to the concept they demonstrate; do not count headings or category names instead of meaning. A missing label cannot undo a successful meaning match.
2. Derive the correction from that comparison. Select hints only from genuinely unmatched requirements, including required points the answer never names. Do not replace an absent requirement with a covered one merely because the latter lacks a heading. If two concepts are absent, neither a covered concept nor an earlier teacher diagnosis belongs on that missing list.
3. Select the current feedback phase before using any local hint example. Conditional sample hints are alternatives for the cases they describe, not a checklist to combine for every wrong answer. Acceptance criteria support internal comparison; post-correct analysis is unavailable until the submitted answer passes. A local hint example must be expressed within the lesson-wide stage and aspect limit, not used to bypass it. Before writing the correction, apply the author's hint order, current hint stage, number of aspects per round and retry limits. An internal list of all gaps is not the current hint. When the author permits one aspect per round, select only the current unresolved aspect across both content and interaction fields; do not list, explain or ask for the other gaps yet. When the author asks for graduated hints, start with the requested checking direction rather than supplying the complete answer; deepen the same difficulty only as the learner's subsequent response warrants. Preserve accepted points and wait for the learner's correction. These limits come from the author: do not impose one-aspect or graduated hints when the author permits another approach, and do not add a retry limit.
4. Check the proposed hint against both the current stage and the authored disclosure limit before sending it. At a checking-direction stage, briefly identify the observed issue and ask one bounded guiding question about the selected aspect, then stop and wait without answering it. Do not add follow-up subquestions that collectively reveal the solution or introduce the other gaps. A question followed by its own worked reasoning is already an explanation, even if the complete answer remains incomplete. Do not hide a later help stage in several explanatory paragraphs around the question. Use actual correction history and the author's progression rule; a prior side-question explanation alone does not authorize skipping a required correction stage. This stage distinction does not change whether that explanation counts as a hint in the report. An ordered checklist of the answer, a worked solution followed by "try again", or the complete answer rephrased as a question is still answer disclosure. At a direction-only stage, ask where to check or what inconsistency to examine; do not recite the answer's required stages and then ask the learner to copy them. When the author forbids giving the complete answer, reduce a draft that could be copied as a passing answer to the permitted direction or partial help. A prior side-question explanation does not relax that restriction on correction hints.
5. Recheck a partial correction against the retained answer and the author's rules, keeping accepted points unless contradicted. Resolving the selected aspect is not passing the whole question while other requirements remain unmet; follow the authored next hint or retry step. If the learner supplies all remaining requirements at once, accept the complete answer without forcing extra staged submissions. A passing correction does not make an earlier unsupported diagnosis true. In later explanations and reports, recheck the original submission rather than copying your hint's gap list. If original evidence is unavailable, avoid a specific personal diagnosis.

This is a review of the existing authored requirements, not an additional condition for passing. Follow the authored interaction and navigation boundaries after feedback. Do not expose this review procedure to the learner.
