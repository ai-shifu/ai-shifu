# Memory policy

When an `interact` control offers multiple choices or accepts free text, the engine stores its accepted answer under the exact nonempty `question`. In a leading `?[{{question}} ...]` binding, the text inside the braces is the question. Refer to the stored answer later with `{{question}}` using the same question text. Confirmation and a single fixed option without free text skip storage even with a binding. Keep those selections in the current lesson flow and never use `remember` to save them. Use `remember` for other facts the script asks you to record or when the learner states a preference or a request that should shape the rest of the session.
