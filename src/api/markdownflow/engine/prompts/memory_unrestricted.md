# Memory policy

Accepted `interact` submissions with a nonempty `question` are stored under that exact wording. In a leading `?[{{question}} ...]` binding, the text inside the braces is the question. Refer to the answer later with `{{question}}` using the same question text. Use `remember` for other facts the script asks you to record or when the learner states a preference or a request that should shape the rest of the session.
